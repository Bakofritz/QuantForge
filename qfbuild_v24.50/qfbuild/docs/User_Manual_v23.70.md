# QuantForge v23.70 User Manual

This release remains simulation-only. Select a historical dataset, verify its identity, and run research or simulation workflows. QuantForge does not connect to a live broker and cannot submit live orders. NT8 may supply local historical data, but the current hard live lock remains in force.

### Live-environment state
- Live brokerage disabled.
- Simulation enabled.
- Data access read-only.
- Future Windows live pathway requires NT8 to be running plus all existing security/recovery gates.
