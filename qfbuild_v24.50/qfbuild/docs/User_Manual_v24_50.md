# QuantForge v24.50 User Manual

## Purpose
This release adds Research Product Candidate Gate.

## Safe workflow
1. Import strategy into quarantine.
2. Audit and scrub features.
3. Commit only governed research components.
4. Use read-only market data.
5. Run simulation/optimization/research analysis.
6. Review validation and provenance.
7. Do not interpret this release as enabling live brokerage.

## Android testing
Use an Android browser with GitHub Codespaces to run the repository's documented validation/build commands. The remote Codespace supplies compute; the phone acts as the control interface.
