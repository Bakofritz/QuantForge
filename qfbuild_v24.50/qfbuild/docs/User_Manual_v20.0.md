# QuantForge Futures Research Platform — User Manual v20.0 Foundation

## What v20.0 is

v20.0 is the native-architecture migration foundation. The previous v19.2 browser application remains the functional prototype and visual reference. This release establishes the shared C# project boundaries and the native MAUI UI skeleton.

## What is usable now

The project defines the target Windows/Android application shell, shared domain contracts, deterministic governance boundary, local evidence/job-storage interfaces, AI non-authoritative contract, Scout quarantine contract, and visual reference contract.

## What is not yet claimed

This foundation is not a compiled production application because the current build environment does not contain the .NET SDK. It does not claim Android packaging, Windows installation, SQLite implementation, network synchronization, or native-device certification yet.

## Safety

Live trading, live orders, arbitrary code execution, canonical data mutation, manifest mutation, and undeclared application mutation remain prohibited architectural authorities.

## Visual behavior

The native shell intentionally follows the established sunflower-radial reference: three columns, eight radial modules, central Research Focus, orbital rings, and contextual rails.

## Migration principle

Do not discard v19.x. Preserve it as reference and progressively move authoritative services into shared native code.
