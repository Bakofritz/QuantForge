## Standing safety directive
- No live trading.
- No live orders.
- No arbitrary/undeclared code execution.
- No canonical market-data mutation.
- No silent application/policy/manifest mutation.
- External Internet content is untrusted data.
- Scout uses quarantine before governed research.
- AI is non-authoritative.

## Device model
Windows and Android may run simultaneously. Each has local state. A logical mutable job gets one execution lease at a time. Immutable evidence/events can be synchronized later. Never use one shared SQLite file over a network filesystem.
