# QuantForge User Manual — v21.10

1. Import a supported strategy into quarantine.
2. Run the first-line static audit.
3. Review detected feature categories and evidence.
4. Select only components intended for canonical research representation.
5. Obtain the explicit research governance decision.
6. Create the research-only capability manifest.
7. Commit the canonical model and provenance chain.
8. Register the model in the research registry.
9. Use the resulting registry entry for governed backtesting/optimization.

The capability manifest is least-privilege. Research registration cannot grant live-order submission. Imported source is never compiled or executed by the static import path.
