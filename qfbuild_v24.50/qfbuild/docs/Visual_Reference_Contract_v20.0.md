# QuantForge v20.0 Visual Reference Contract

The previously generated QuantForge sunflower-radial concept remains the authoritative visual target.

## Required desktop composition

1. QuantForge identity at upper left.
2. Analyze / Test / Improve / Trade Smarter centered in the header.
3. System status/version/settings area upper right.
4. Three-column body: contextual rail / large radial workspace / contextual rail.
5. Eight organic radial modules around a dominant central Research Focus.
6. Concentric orbital geometry and subtle radial separators.
7. Left rail: Current Project, Recent Activity, Quick Actions.
8. Right rail: System Overview, Active Bots, Recent Discoveries.
9. Dark near-black foundation with sunflower gold and restrained secondary accents.
10. Legacy chart functionality remains accessible but does not reclaim primary-home hierarchy.

## Fidelity rule

Functional equivalence is not visual completion. Future builds must compare rendered output to the reference and correct material deviations in spacing, scale, hierarchy, proportions, typography, radial geometry, and information density.
